Okta Virtuoso
?
Internal API warning: Virtuoso is a branch of Okta Rockstar. It uses internal, undocumented Okta APIs where no public equivalent exists. Every affected feature is labeled. These APIs can break at any time.

Enhance Okta with these features:

  • Export Objects to CSV: eg, Users, Groups, Group Members, Group Rules, Directory Users, Apps, App Users, App Groups, App Notes, Network Zones, YubiKeys, Mappings, Admins...
  • User home page: Show SSO (SAML assertion...)
  • People page: enhanced search
  • Person page: show login/email and AD info, show user detail, enhance menus/title, manage user's admin roles, verify factors
  • Groups page: search using regular expressions (like wildcards)
  • Active Directory page: show OU tooltips, export OUs
  • Identity Providers page: show SAML certificate expiration date
  • Events: Expand All and Expand Each Row
  • API: API Explorer, Pretty Print JSON
  • Many: enhanced menus
...and more to come

Setup

Virtuoso is installed as an unpacked Chrome extension. The original Okta Rockstar extension is available on the Chrome Web Store.

Usage

  1. Login to Okta or Okta Admin.
  2. Navigate to, e.g., Directory > People or Security > Administrators, etc.
  3. Look for the Virtuoso popup window in the upper-left corner of your browser.
